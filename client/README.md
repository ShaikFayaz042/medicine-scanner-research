# Medicine Scanner Client

The client is a Vite + React frontend. Its application source, styles, and UI components live in this directory.

## Run locally

```powershell
npm install
npm run dev
```

The development server proxies API, health, PDF, and WebSocket requests to the backend at `http://localhost:8000`. Start the repository's Python server separately when using backend-backed features.

## Build and lint

```powershell
npm run build
npm run lint
```
